Invision — Biblioteca BCC

Propuesta de Implementación: Bibliotecario Digital Agéntico

🌟 Introducción y Propósito

Las personas con ceguera y baja visión navegan la web de manera secuencial (leyendo o escuchando elemento por elemento de arriba a abajo). Encontrar un libro específico en una biblioteca digital tradicional requiere decenas de clics y búsquedas exactas, lo cual genera fatiga cognitiva y frustración.

La **Propuesta Agéntica** consiste en implementar un **Bibliotecario Digital** basado en Inteligencia Artificial. Este asistente actúa como un intermediario inteligente: procesa la voz libre y coloquial del usuario, interpreta su necesidad semántica, busca en el catálogo y le entrega recomendaciones personalizadas y audiolibros al instante.

📊 Comparativa: Invision Tradicional vs. Invision Agéntico

Característica Caso Actual (Básico) Propuesta Agéntica (IA)
Búsqueda de Libros Exacta por texto (debe coincidir con la base de datos). **Semántica y Coloquial:** Entiende intenciones ("para relajarme", "de misterio corto").
Canal de Interacción Uso obligado de teclado, mouse o lector de pantalla tradicional. **Conversación por Voz Fluida:** Diálogo hablado natural en español.
Estructuración de Catálogo Mapeo rígido en base de datos; archivos de audio subidos a mano. **Ingesta Inteligente:** IA que clasifica géneros, limpia ruidos y segmenta capítulos.
Retención de Lectura Solo guarda segundo y capítulo. **Memoria Contextual:** Recuerda la trama y ofrece resúmenes al vuelo.

🏢 Blueprint: Recursos e Infraestructura Necesaria

Para que el proveedor implemente esta solución basada en el backend de FastAPI existente, se requiere la habilitación y aprovisionamiento de los siguientes servicios en la nube:

1. Servicio de Large Language Models (LLM)

  • API Key de **Gemini 1.5 Flash** (Google AI) o **Azure OpenAI** (GPT-4o).
  • Aprovisionamiento de cuotas de procesamiento (Tokens por minuto) en producción.

2. Base de Datos Vectorial (Para Búsqueda Semántica)

  • Habilitar la extensión **vectorial** en el servidor de base de datos actual (ej. `pgvector` en PostgreSQL o búsqueda semántica en Azure SQL).
  • Provisionar espacio de almacenamiento para índices de embeddings de libros.

3. Actualización de API y Servidor

  • Habilitar puertos y balanceadores de carga para soporte de conexiones persistentes de **WebSockets**.
  • Configuración de internet saliente (egress proxy) en la red virtual del contenedor API para comunicación segura con el proveedor de IA.
